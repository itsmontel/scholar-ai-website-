# Free ebook for new sign-ups

Place your PDF here so it is served to users who sign up.

**Required filename:** `writescholar-ultimate-study-tips-guide.pdf`

- **URL (production):** `https://writescholar.com/downloads/writescholar-ultimate-study-tips-guide.pdf`
- **Suggested length:** 10–12 pages
- **Suggested title:** WriteScholar Ultimate Study Tips Guide

New users receive a link to this PDF in their welcome email (after verifying their email). The same download is available from the dashboard.

Create your PDF with the content, then save it in this folder with the exact filename above. Do not commit large binaries to git if you prefer; you can add this folder to `.gitignore` and upload the file on your host instead.
